# Система промокодов для UrbanGo

## Описание

Система промокодов позволяет применять скидки к стоимости аренды автомобилей в системе каршеринга UrbanGo.

## Новые компоненты

### 1. Модель данных (Model)

**PromoCode.cs** - класс промокода:
- `Id` - уникальный идентификатор
- `Code` - уникальный код промокода
- `DiscountPercent` - процент скидки (0-100)
- `IsActive` - активен ли промокод

### 2. Слой доступа к данным (DataAccessLayer)

**IPromoCodeRepository.cs** - интерфейс репозитория промокодов:
- Наследует от `IRepository<PromoCode>`
- `GetByCode(string code)` - поиск промокода по коду

**EFPromoCodeRepository.cs** - реализация через Entity Framework
**DapperPromoCodeRepository.cs** - реализация через Dapper

### 3. Бизнес-логика (BusinessLogic)

**PromoService.cs** - сервис для работы с промокодами:
- `ApplyPromoCode(string promoCode, decimal originalPrice)` - применение промокода

Дополнительно для изоляции UI от DAL добавлены:
- `IPromoService` — интерфейс для использования в UI
- `PromoServiceAdapter` — адаптер над `PromoService`, чтобы не менять существующий класс

### 4. Обновления существующих компонентов

**CarService.cs**:
- Добавлена зависимость от `PromoService`
- Метод `CalculateRentalCost` теперь принимает необязательный параметр `promoCode`

**CalculateCostForm.cs** (WinForms):
- Добавлены элементы управления для ввода промокода
- `txtPromoCode` - поле ввода промокода
- `btnApplyPromo` - кнопка применения промокода
- `lblDiscountInfo` - отображение информации о скидке

**Console приложение**:
- Обновлен метод `CalculateCost()` для ввода промокода

## Установка и настройка

### 1. Создание таблицы в базе данных

Выполните SQL скрипт `CreatePromoCodesTable.sql`:

```sql
-- Создание таблицы
CREATE TABLE PromoCodes (
    Id int IDENTITY(1,1) PRIMARY KEY,
    Code nvarchar(50) NOT NULL UNIQUE,
    DiscountPercent decimal(5,2) NOT NULL CHECK (DiscountPercent >= 0 AND DiscountPercent <= 100),
    IsActive bit NOT NULL DEFAULT 1
);

-- Создание индекса
CREATE INDEX IX_PromoCodes_Code ON PromoCodes (Code);
```

### 2. Тестовые данные

В скрипте уже включены тестовые промокоды:
- `WELCOME10` - скидка 10%
- `SAVE20` - скидка 20%
- `STUDENT15` - скидка 15%
- `FIRST5` - скидка 5%
- `VIP25` - скидка 25%
- `EXPIRED` - неактивный промокод (для тестирования)

## Использование

### WinForms приложение

1. Запустите приложение
2. Выберите провайдер данных (Entity Framework или Dapper)
3. Перейдите к расчету стоимости аренды
4. Введите промокод в поле "Введите промокод"
5. Нажмите "Применить промокод"
6. Система покажет размер скидки и итоговую стоимость

### Console приложение

1. Запустите консольное приложение
2. Выберите провайдер данных
3. Выберите пункт "8. Рассчитать стоимость аренды"
4. Введите ID автомобиля и количество часов
5. Введите промокод (или оставьте пустым)
6. Система покажет итоговую стоимость

### Архитектура
- Система следует существующей архитектуре проекта
- Поддерживает оба провайдера данных (EF и Dapper)
- Промокоды интегрированы в существующий процесс расчета стоимости
- UI получает зависимости только через `(ICarService, IPromoService)` — создание репозиториев инкапсулировано в `BussinessLogic/ServiceFactory`

### Обработка ошибок
- При неверном промокоде показывается сообщение "Промокод не найден"
- При успешном применении показывается "Скидка X% применена"
- Неактивные промокоды отклоняются

## Тестирование

### Тестовые сценарии

1. **Валидный промокод**: Введите `WELCOME10` - должна примениться скидка 10%
2. **Неактивный промокод**: Введите `EXPIRED` - должно показать ошибку
3. **Несуществующий промокод**: Введите `INVALID` - должно показать ошибку
4. **Пустой промокод**: Оставьте поле пустым - расчет без скидки

### Проверка работы

1. Запустите приложение
2. Создайте тестовый автомобиль
3. Перейдите к расчету стоимости
4. Попробуйте применить различные промокоды
5. Убедитесь, что скидки применяются корректно
